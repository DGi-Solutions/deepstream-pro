# Herkunft

DeepStream Pro ist eine veränderte Ausgabe von Jellyfin Desktop, kein offizielles Jellyfin-Release.

- Upstream: https://github.com/jellyfin/jellyfin-desktop
- Ausgangscommit: `3fa72e5df57ab52c907b65bb42f2a05b7ae25cd6`
- mpvqt: https://invent.kde.org/libraries/mpvqt.git
- mpvqt-Commit: `2ebbd38bf65d01be9c55d673ecd43c8bb9a6fc8e`
- Ursprüngliche Lizenz: [GNU GPL v2](../LICENSE)
- Historische Projektbeschreibung: [UPSTREAM-README.md](UPSTREAM-README.md); deren Plattform- und Downloadangaben gelten für den Upstream.

Unsere Änderungen umfassen die separate App-/Profil-Identität, experimentelle AVFoundation-Auswahl mit Rückkehr zum vorherigen Ausgang, Trailer-Ansteuerung, native Paketierung, DGi-Branding und die weitere macOS-Audioentwicklung.

Der bestehende Code und seine Urheberhinweise werden erhalten. DGi Solutions verantwortet die Änderungen und den Projektauftritt von DeepStream Pro. Es wird keine Partnerschaft oder Zertifizierung durch Jellyfin, Apple, Dolby, DTS oder FiiO behauptet.
